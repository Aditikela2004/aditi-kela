Portfolio action tracker

Meetings produce action items, and action items vanish. This tracker keeps one log across programs and flags what is overdue without anyone having to chase it.

Role
Built it as a project management intern
Built in
Excel
Status
Template built, automation in progress
Skills shown
Action and issue tracking, governance reporting, status reporting, dashboards, Excel

The problem

Weekly syncs generate actions with owners and dates. They live in meeting notes, and the only way to learn that one slipped is to ask.

What I built

An action log where each row has an ID, the date it was raised, the action, the related program, who raised it, who owns it, priority, target dates, actual dates and status. The dashboard counts actions by status, priority and department, and shows how many are overdue.

How it works

Overdue is a formula, not a judgment call. It compares the target end date with today and ignores completed actions. Status and priority come from dropdowns so the counts stay clean.

What comes next

The log still needs manual entry. I started on automation so that actions captured in meetings flow into the tracker without retyping.
