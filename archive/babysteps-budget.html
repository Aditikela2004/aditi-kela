Summary

At 100 active families the app costs roughly $93 a month with the larger model or $53 with the smaller one, almost all of it hosting. At 1,000 families the AI line starts to matter. The smaller model keeps the AI cost under $21 a month at that size. Estimate

Usage assumptions

  • Each active family triggers 12 guidance requests a month, each with about 1,200 input and 500 output tokens. Estimate
  • Planned chatbot: 6 conversations a month per active family, 6 turns each, about 2,500 input and 400 output tokens per turn. Estimate
  • Whether the app calls the Claude API directly or through Base44's built-in integrations decides how this cost is billed. The tables assume direct API pricing. To confirm

Break-even view

At 1,000 active families and the smaller model, monthly cost is about $72. A $4.99 monthly plan would need about 15 paying families to cover it, before payment fees. That is about 1.5% of 1,000 families. Estimate

Cost controls

  • Use the smaller model for routine guides and keep the larger one for the chatbot.
  • Cache generated guides by country and age, so the same guide is not generated twice.
  • Set a monthly spending limit in the API console and alert at 80%.
  • Review the bill each month during the beta.
