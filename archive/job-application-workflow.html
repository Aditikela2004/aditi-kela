AI job application workflow

A Claude-powered workflow that finds relevant postings and prepares a tailored resume, cover letter and form for each one. It always stops before submit so a person reviews first.

My role
Designed the workflow and its rules. Run it daily.
Context
Personal project, used on my own job search
Tools
Claude, browser automation
Output
A batch of about 15 tailored application packages per session
Skills shown
AI workflow design, generative AI, Claude, human-in-the-loop controls, process automation, data validation rules

The problem

Applying to dozens of roles means re-tailoring a resume and a letter every time. Done fast by hand, it produces errors. Done fully automatically, one wrong claim can sink an application.

The rules I set

  • Every claim must come from a bank of experience I've confirmed. No invented skills.
  • Posting keywords are used only where my real experience backs them.
  • Eligibility problems, such as location or experience asks, are flagged before any writing.
  • The workflow fills the forms and stops. I review and press submit myself.

How it improved

Every error became a new rule. Early drafts had claims I couldn't back up, so I added a check against the fact bank. Resumes spilled onto a second page, so layout fitting became part of the run.

Why it matters

This is the pattern I'd use for any team: let generative AI do the repetitive drafting and data entry, write the validation rules down, and keep a person accountable for anything that goes out.

How a posting becomes an application

  1. FindClaude finds relevant postings.
  2. CheckEligibility problems are flagged before any writing.
  3. TailorResume and cover letter use only experience I've confirmed.
  4. FillThe form is filled in, then the workflow stops.
  5. I reviewA person reads it and presses submit.
