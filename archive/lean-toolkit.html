Lean manufacturing workbook

A 5S audit form scores an area from 1 to 4 on each of the five S categories and rolls the scores into an overall result. A poka-yoke register lists each mistake-proofing control with the process step, the error it prevents, whether it prevents or detects, its owner and status. A project tracker compares baseline, target and actual for metrics such as right-first-time rate and rejection rate. One dashboard pulls from all three.

Heijunka schedule workbook

Heijunka means leveling the schedule so work flows evenly. The workbook starts with a demand and takt time calculator, builds a weekly schedule board that spreads batches across the days, and produces a daily production sequence with status. The dashboard shows takt time by product and the mix by day.

Andon stock board

An andon is a signal that something needs attention. This board turns months of stock on hand into red, yellow and green using thresholds the user sets, lists open backlog lines for filled product, and tracks obsolete items. A runway chart shows which items need attention first.

Why templates

Each one has an example row to show the intent and a dashboard that updates as rows are added, so a team can start with a working example instead of a blank sheet.
