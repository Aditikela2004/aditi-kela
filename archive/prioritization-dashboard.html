Project prioritization dashboard

Capital planning conversations go better when every project is scored the same way. I built a five-factor scoring model with a dashboard on top, so leadership can compare projects side by side.

Role
Designed and built it as a project management intern
Built in
Excel
Status
Built and demonstrated with sample data, recommended for quarterly review
Skills shown
Portfolio prioritization, weighted scoring model, RAG status reporting, executive KPI dashboards, Excel

The problem

Projects compete for the same budget, people and shutdown windows. Without a shared yardstick, the loudest request tends to win, and nobody can see which projects have no executive sponsor at all.

The scoring model

Each project is scored on strategic alignment (30 percent), financial impact (25 percent), complexity risk, resource risk and urgency (15 percent each). Risk factors are inverted so that a riskier project scores lower. Capital and operating cost ranges convert to scores through a criteria table, which keeps the scoring rules visible and easy to change.

What is on the dashboard

KPI tiles, a RAG health summary, five charts and a heatmap of business value against strategic alignment, with total cost shown alongside. The whole page filters by business unit or function. A project with no sponsor is flagged automatically.

How I built it for other people to use

Dropdowns control every input, a guidance tab explains the steps, and the scoring tab does the arithmetic so a user only enters facts about a project. The point was a tool someone else could run next quarter without me.

Where it stands

I demonstrated it with sample data in my internship review and recommended it as a standing tool for quarterly portfolio review. It has not been adopted yet, so I describe it as built and ready, not as in use.
